# 🎵 Flute Notation

A user-friendly website for searching, learning, and practicing flute notations of popular Telugu songs.

## 🌟 About the Project

Flute Notation is a web-based platform created for flute players and music enthusiasts who want to easily find flute notations for their favorite Telugu songs.

The website provides:

- 🎶 Popular Telugu song flute notations
- 🔍 Easy song search
- 📝 Lyrics with corresponding flute notations
- 🎼 Flute-friendly notation
- 📱 Responsive design for mobile, tablet, and desktop
- 🗄️ Supabase database for storing and retrieving song information
- 📖 Clean and easy-to-follow notation presentation

The main goal of this project is to make learning and practicing Telugu song flute notations simple, accessible, and enjoyable.

## 🎯 Features

### 🔎 Search Songs
Users can search for their favorite Telugu songs and quickly find the available flute notation.

### 🎵 Lyrics & Notation
Lyrics are displayed together with their corresponding flute notation.

Lyrics line 1
